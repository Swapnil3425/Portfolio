# Modern Engineering Portfolio

A premium, interactive portfolio built with **Next.js**, **Framer Motion**, and **Spline**. This project features smooth animations, 3D interactive elements, and a mobile-optimized project showcase.

![Portfolio Preview](public/site-logo.png)

## 🚀 Experience the Design
- **3D Interactive Hero**: Features an interactive robot powered by Spline.
- **Contact System**: Fully functional contact form integrated with **Resend API**, featuring real-time inline email validation and server actions.
- **Micro-animations**: Smooth transitions and hover effects using Framer Motion.
- **Glassmorphism UI**: Modern aesthetic with frosted glass effects and ambient glows.
- **Mobile Optimized**: Custom stacked-card carousel for projects on mobile devices.
- **Responsive Layout**: Designed for seamless experience across all screen sizes.

## 🛠️ Tech Stack
- **Frontend**: Next.js 15, React 19
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **3D Graphics**: Spline (@splinetool/react-spline)
- **Icons**: Lucide React
- **Email Service**: Resend

## 📦 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Swapnil3425/Portfolio.git
cd Portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Setup Environment Variables
Create a `.env.local` file in the root directory and add your Resend API key:
```env
RESEND_API_KEY=your_resend_api_key_here
```
*(Reference `.env.example` for the template)*

### 4. Run the development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### 5. Build for Production
```bash
npm run build
```
